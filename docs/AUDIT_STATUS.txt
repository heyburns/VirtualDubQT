Audit remediation checklist
===========================

Updated from the 2026-10-02 audit and implementation plan. Each checked item
requires focused regressions, a rebuilt-application smoke check, and a local
commit. An unchecked item is not resolved merely because the existing suite
passes. The separate codec troubleshooting suite is excluded. Hardware tests
and the user's unreproduced progressive ProRes slowdown require separate evidence.
