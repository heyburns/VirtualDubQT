VirtualDubQT v0.1.1 is the first packaged preview release of the native Linux port of VirtualDub2.

Highlights:

- Native Qt 6 interface with the familiar VirtualDub editing workflow.
- Video playback, timeline scrubbing, filtering, audio processing, and FFmpeg-based export.
- Direct Stream Copy, Fast Recompress, Normal Recompress, and Full Processing modes.
- AviSynth+ and supported VapourSynth script input.
- Batch Wizard, Job Control, projects, processing settings, capture, and command-line automation.
- Recent stability fixes for media loading, AviSynth script reloads, export preview, and rapid playback start/stop.

This remains an early preview. Read the Important Requirements and current feature-status sections in the README before relying on it for important work.

Downloads:

- `VirtualDubQT-0.1.1-x86_64.AppImage`: portable build for 64-bit Linux.
- `virtualdubqt_0.1.1_amd64.deb`: package for Ubuntu 24.04 and compatible systems.
- `virtualdubqt-0.1.1-1.x86_64.rpm`: package for Fedora 43 and compatible systems.
